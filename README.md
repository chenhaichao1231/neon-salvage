# 校园防线 · Campus Defense

**[在线试玩](https://chenhaichao1231.github.io/neon-salvage/)** · [English](README.en.md)

## Demo 0.10.1

五行校园塔防：收取GPU算力，安排DeepSeek和GPT守卫，拦住右侧的数据怪。本版包括3个入门关、2敌绕行练习和9敌合流车队挑战。

- **DeepSeek**：50 GPU，低价直射；预告后偶尔吃饭2秒，暂停射击。
- **GPT**：90 GPU，每发最多穿透2个目标；预告后偶尔弱输出3秒，伤害为70%。
- 角色行为是虚构游戏设定，不是现实AI产品评测。本版仅开放DS/GPT。

### 本次改进

- **紧急撤离**：每局一次，未暂停时选中存活守卫，返还半价25/45 GPU。原有准备期全额撤回不限次。已发射弹道和已承诺的转行继续执行；过早撤走引流守卫可能让后续敌人直行。
- **低生命反馈**：半血时血条变暖，四分之一生命时增加静态高对比感叹号。选中摘要和格子无障碍标签显示“低生命”。这是当前生命状态，不保证有足够反应时间，也不自动建议撤离。
- **看懂布阵**：部署后自动选中，标出真实的本行向右射界。守卫不会回头攻击已经越过自己的敌人。
- **战况比较**：结算区分被击败和主动撤离，退款不降低累计部署花费。同一会话、同一关卡与随机计划可比较上次完整尝试；只有两次都获胜时才比较通关速度。
- **现有动作与载入**：DeepSeek待机、状态和收势遵循战斗时钟；实际最后一发收招后休息。碎片、重甲和GPT保留事件驱动动作。首关延后请求约4.03 MiB用不到的敌人动作图，未据此宣称实际提速。

### 操作与策略

选角色，再点空格部署；准备好后开始。战斗中可以补位、紧急撤离、暂停和切换1×/2×。重试恢复开战前的部署、GPU、同一状态计划与未使用的撤离次数，不带走本次收益。

每6战斗秒掉落30 GPU，点击可提前领取，4秒后自动到账且不消失。每关总补给300 GPU，胜利结清余量。战中撤离退回的GPU不算补给；原格重新部署仍收全价并创建新守卫，净支出25/45 GPU且消耗唯一撤离次数，并非免费治疗。

合流车队中，第2行三只冲锋可被守卫引入第3行，与六只碎片汇合。进入守卫前方两格时停2秒，再转一次；等待时仍可受伤。放置位置、撤离时机和接收行火力都重要。任一敌人漏过即挑战失败。省钱和快清是本局比较目标，没有永久数值成长。

浏览器只保存已到达关卡和语言。刷新回到180 GPU空阵准备，不保存半场战斗或最佳阵容。战斗及非空准备期间禁用关卡切换。无需账号或付费。

### 验证与限制

发布准备时20个本地测试套件通过，其中18个检查当前游戏，另2个检查历史引擎/UI。局部真实引擎对照验证了撤离的时机、对象与补位位置会产生不同结果；这些结果不等于真人可玩性或全面平衡验证。

已检查1120×650和740×400的本地Canvas画面，包括美术加载与两种备用显示。这不是浏览器布局、屏幕阅读器、手机触控或性能验收。**本次发布准备尚未完成这些实际设备检查。**

这是2D精灵原型，动画、身体细节和移动仍有限。全套图片超过20 MiB，首次载入可能较慢。素材生成不证明角色权利或商业授权。旧源码和历史测试仍保留，不属于本版当前游戏验收。

本地可使用Node.js逐个运行相关测试，例如 `node td-lanes.test.js`、`node td-lanes-ui.test.js`、`node td-emergency-withdraw.test.js`、`node td-lanes-low-health.test.js`。部分绘图检查使用 `@napi-rs/canvas`；旧原型测试不应与当前游戏检查混为一谈。
