# 校园防线 · Campus Defense

**Demo 0.13** · [在线试玩](https://chenhaichao1231.github.io/neon-salvage/) · [English](README.en.md)

五行校园塔防。收取 GPU，安排四种 AI 守卫，挡住从右侧进入的数据怪。

## 开始游戏

1. 选择角色，再点击空格子部署。守卫只向右攻击，建议先观察各行预告。
2. 准备好后点击“开始入侵”。战斗中可以用新补给继续部署。
3. GPU 每 6 战斗秒投放 30 点，点击立即领取，不点击则 4 战斗秒后自动到账。
4. 暂停时可以部署、领取现有 GPU、使用紧急撤离。部署立即扣费；未来补给与战斗时间冻结，点击“继续”恢复。
5. “重试本关”恢复开战前的布阵、GPU 和同一随机状态计划，可以重新安排策略。

## 四种基础守卫

四种角色从第一关即可使用。角色行为是虚构游戏规则，不是现实 AI 产品评测。

- **DeepSeek · 50 GPU**：低价直射，10 伤害 / 1.1 秒。偶尔在预告后吃饭 2 秒，暂停射击。
- **GPT · 90 GPU**：14 伤害 / 1.4 秒，每发最多穿透两个不同目标。偶尔进入 3 秒弱输出，伤害为 70%。
- **Claude · 120 GPU**：30 伤害 / 2 秒，单体无视装甲。复核前预告 2 秒，然后自动离线 3 秒再恢复。复核不问玩家问题、不判断国籍、不读取个人信息。
- **Grok · 80 GPU**：16 伤害 / 1.8 秒，首次命中波及本行 0.8 格内最多三个目标。每第四发变为 4 伤害的“烂输出”，射空也计数；下一发进度和实际弹道质量分别显示。

不同敌群适合不同选择。便宜铺场、集中穿透、重击装甲、处理紧密集群各有用途，四种角色并非每关都要买齐。

## 波次与经济

- 四个主线关分别有 **30、50、54、43 名敌人**，按 **3、4、4、4 段**推进；最后来袭时间为 55、57.25、68、61 战斗秒。各行预告和分段时间表可以随时查看。
- **主线 4 · 转移的压力**：第 3 行先迎来碎片群，随后第 5 行、再到第 1 行出现碎片与冲锋。43 名敌人分四段来袭，起点为第 4、22、36、53 秒。使用普通的五核心生存目标，不要求零漏敌，也没有转行路线。把后续补给留给下一段压力；廉价直射补强与不同专长搭配都有可行方案。
- 另有两个可选机制练习：2 名敌人的一次绕行、9 名敌人的合流车队。练习要求零漏敌；绕行一旦开始蓄力，不会因守卫撤离而取消。
- 每关初始 180 GPU，固定补给共 300 GPU，不按击杀额外给钱。早胜不会损失尚未发放的补给。
- 准备阶段可以全额撤回。每场战斗只有 **一次**紧急撤离额度，DS / GPT / Claude / Grok 分别退回 25 / 45 / 60 / 40 GPU。
- 撤离不删除已经发出的弹道；重新部署仍收全价。主动撤离与被击败分开统计，退款不算补给，也不抵扣累计部署花费。
- 1× / 2× 改变推进速度，不改变战斗规则。切换到后台会自动暂停，返回后需手动继续。

## 显示与进度

右侧留白足够容纳预告时，各行预告会移到该留白中；较窄布局保持原有位置。

未来来袭预告现在分两行显示“下一批 5s”和敌人类型，与在场敌人区分。相邻敌群有空间时会显示各类型的图形与数量，图例位于现有玩法说明中；空间不足时只显示总数，连总数也放不下时省略额外计数。入口处尤其是窄屏仍可能重叠，本次没有移动敌人或生命条。敌群计数不代表共享生命或一发能命中的目标数。

可选战后记录新增 Grok 实际命中至少两个不同目标的发数：同一发命中第三个目标不重复计数，弱输出只要实际命中两个目标也计入。这是命中事实，不是伤害或效果排名。Demo 0.13 新增“转移的压力”，原有五个关卡、四种守卫、战斗数值、经济、动作和精确重试规则均保持不变。

角色有待机、攻击和状态动作；低生命会变色并显示提示。顶部 AMD 供给者名牌为“苏姿丰 / Lisa Su”。美术加载失败时会显示提示并使用备用显示，游戏逻辑继续运行。

存储可用时，语言和可用关卡保存在当前浏览器。主线 3 胜利时立即保存主线 4 的入口，下一关直接前往主线 4；两个练习仍是可选内容。旧存档若已到达任一练习，也可直接进入主线 4，无需先完成练习。仅记住主线 3 的旧书签不能证明曾获胜，不会据此自动解锁主线 4。刷新会在记住的关卡以 180 GPU 空阵重新准备；重试则精确恢复开战前的部署与资源。当前战局与对比记录不会跨设备同步；同一会话内可查看漏敌、守卫损失、撤离及同关同随机计划的重试结果。

这是使用生成素材的 2D 美术预览版。首次加载的图片较大，可能需要等待。生成素材不代表已取得角色或商业使用许可。手机实机、触控、读屏和性能专项验收尚未完成。

## 本地运行与检查

无需后端。用静态服务器打开仓库根目录，例如：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8000/`。

使用 Node.js 可运行 `td-*.test.js`；部分绘图检查需要 `@napi-rs/canvas`。

```sh
for test in td-*.test.js; do node "$test" || exit 1; done
```

Demo 0.13 发布前的 32 个相关测试套件通过。自动测试与固定策略模拟不是完整设备验收，也不能证明每种布阵的平衡或真人趣味性。仓库内旧原型文件不属于当前游戏入口。
