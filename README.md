## 搭配 Demo 0.5

AI角色守住五行防线，收集显卡算力、安排部署，阻止失控数据到达左侧核心。本版先验证基础操作与两种角色，不是最终美术或完整平衡版。

**自0.2起，方块占位图已替换为按已确认概念图生成的校园、角色、补给人物和数据怪物素材。角色会在战斗/吃白饭/卡住状态切换，核心玩法未改。仍是二维精灵原型，不是最终动画。未直接打包社区原图；生成素材不代表原角色的第三方许可已核实，不授权其商业再利用。**

- 选择下方DS或GPT，再点空格部署；点“开始入侵”。右侧显示各行下一位来敌，详细时间表可展开。
- DS费用低，偶尔预告后吃白饭2秒暂停射击。GPT现在每一发最多穿透两个目标，单体伤害相应降低，偶尔预告后3秒伤害降至70%。都有恢复提示；这些是虚构游戏规则，不是对现实产品的事实评价。
- 顶部定时掉落GPU。可以点击，也会在4秒后自动收取，不会消失；每关总补给固定，拖延不会无限刷资源。
- 准备期可全额退回角色；战斗中可以补位。支持暂停、2倍速度、同一安排重试及中英切换。胜利后也能点“再试本关”，保留原种子和开战前部署，不携带本次赚到的GPU。
- 三个短关。目前廉价单位策略可能偏强，下一轮将重点检查不同搭配和部署是否真正有意义，而非只增加关数。
- 本Demo尚未保存游戏进度，刷新会重新开始。没有账号、付费或个人身份收集。

旧游戏已从本地当前项目移除，线上旧文件清理仍在进行；Git历史保留。此前独立旧版ZIP下载包已移除。

## 回来可以试什么

- 第二关后段加入紧密三连碎片，留出的补位算力能真正用上；重叠敌人标明×N数量。
- GPT不用等第四发才穿透：每发最多命中2敌，费用仍90，伤害14、间隔1.4秒；DS费用50、伤害10、间隔1.1秒不变。低价铺场与群体打击各有代价，不强制某个搭配。
- 每关开战前给一句具体目标。结算显示核心、角色损失和花费，可在同一安排下比较更省的布阵。

## 已保留的动作表现

DeepSeek攻击改为统一脚位的蓄力、前推、释放与独立收势，不再把蓄力帧倒放当恢复；待机眨眼和抱碗抬筷、咀嚼保留。命中、击碎与受伤反馈由真实战斗事件驱动，暂停会冻结，重试会清空；不改变伤害和资源规则。显卡会从上方四位供给者位置轮流抛出，可点击区域跟随轨迹。GPT与敌人仍为原有静态姿势，不把它们算作已完成动画。
