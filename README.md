## 回来可以试什么

- 可选挑战：绕行冲锋怪离本行前方守卫两格内时，原地停2秒（仍可受伤），再按箭头换到第3行一次。没有本行守卫就直走；落点被守卫挡住则正常交战。准备期高亮实际两格触发范围，战斗中显示目标行和倒计时。可以用两DS分别守两行，也可以试前置DS诱导到GPT的穿透线上；不强制唯一解法。

- 0.7碎片蝙蝠有真实振翅、接触前扑和受击姿态；不是整张贴图上下移动。小尺寸受击细节仍有限。
- 到过第二或第三关后，刷新不再强制重打第一关。关卡选择器可回已到达关，战斗中或已布阵时禁用，防止误删当前布阵。胜利后需点“下一关”才登记到达；没有跨关GPU、奖励或分数。

- 第二关后段第1、3行各来6只碎片，其余行各1只，总敌人数和数值不增加。每行廉价铺场仍能赢，重点行穿透可更快清群；重叠活敌标明×N数量，准备期“来袭计划”另列尚未开始的全关总数。
- GPT不用等第四发才穿透：每发最多命中2敌，费用仍90，伤害14、间隔1.4秒；DS费用50、伤害10、间隔1.1秒不变。低价铺场与群体打击各有代价，不强制某个搭配。
- 每关开战前给一句具体目标。结算显示核心、角色损失、花费和实际清场时间，可在同一安排下比较省钱与快清。剩余GPU不带到下一关，省钱只是本关投入与应急余量，不是永久成长奖励。
